# Terms that raise an automatic flag for a moderator without blocking the
# write.
#
# Ordinary profanity. Somebody swearing at a build is not the same thing as
# somebody swearing at a person, and no word list can tell those apart --
# so the content is stored, the author is not interrupted, and a human
# decides. A term here costs a moderator ten seconds when it is wrong,
# which is why this list can be broader than the blocked one.
#
# Same format as profanity-blocked.txt: one term per line, lower case,
# singular, no trailing comments. Casing, plurals, suffixes, padded letters,
# leetspeak, accents and homoglyphs are handled by the matcher.
#
# Left out on purpose, because a professional platform that flags them ends
# up with a queue nobody reads: damn, hell, crap, wtf, suck. The bar is
# roughly "would this get a comment removed if it were aimed at a person".
